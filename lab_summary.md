# Prompt Engineering Lab Summary

In this lab, I explored how different prompt engineering techniques affect the consistency and reliability of AI-generated outputs across three tasks: sentiment analysis, product description generation, and data extraction. I tested zero-shot prompts, structured instructions, few-shot examples, and step-by-step prompting using GPT-4o-mini. Each prompt version was evaluated through 15 repeated runs. The results showed that structured instructions improved exact-response consistency from 13.3% to 100% for sentiment analysis and from 46.7% to 100% for data extraction. Product descriptions maintained approximately 6.7% exact-response consistency across all versions, although both structured versions achieved 100% length compliance. These findings highlighted the importance of choosing evaluation metrics that match the task, distinguishing output variation from actual errors, and avoiding unnecessary prompt complexity. My main takeaway is that effective prompt engineering requires clear requirements, systematic testing, and evidence-based improvements rather than assuming that more elaborate prompts always produce better results.
